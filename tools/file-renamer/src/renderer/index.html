Rules

Add a rule to start. Rules run from top to bottom; drag them or use the arrows to change the order, and untick one to skip it. Nothing is renamed until you press Rename.

Drop files or folders here or use Add files… / Add folder…

You see every new name before anything changes. Names that would clash, that Windows cannot use, or that are too long are marked, and renaming waits until they are fixed. Every batch can be undone, also after closing the app.
