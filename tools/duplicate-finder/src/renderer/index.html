Folders to scan

Drop folders here

    A protected folder is a place you trust: its copies are always kept and can never be moved.

    Finds songs whose sound is identical, and songs with the same artist and title and about the same length (for example an MP3 and a FLAC of one track). It does not listen to the music, so a song with different tags or a different recording is not matched.

    Find files that are there more than once

    • Nothing is deleted for good: files go to the Recycle Bin, where you can get them back.
    • You review every group first. At least one copy of each always stays.
    • Files that changed since the scan, or that are no longer identical, are left alone.
