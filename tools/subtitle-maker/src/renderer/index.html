Drop a video or audio file here MP4, MKV, MOV, WebM, AVI, MP3, WAV, M4A and more, up to 3 hours. Or drop an .srt / .vtt file to edit it.

What is said in the file is written down on this computer, offline, as subtitles that follow the usual rules (two lines at most, readable speed). You can watch them on the video, fix any word or time, save an .srt or .vtt file, or write a new MP4 with the subtitles in it. The original file is never changed.
