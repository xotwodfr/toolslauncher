Your passwords are kept in one encrypted file that you choose. Put it wherever you like and back it up or sync it yourself; nothing is ever sent anywhere.

New vault

Pick a master password you can remember and nobody can guess: four or five random words work well. It cannot be recovered: if you forget it, the vault cannot be opened by anyone, including you.

Key file (optional second factor)

With a key file the vault opens only with the password and that exact file. Keep a copy of it somewhere safe: without it the vault is lost.

    Export an unencrypted CSV

    Every password will be written in plain text. Anyone or any program that can read the file can read all your passwords, and copies can linger in backups, sync folders and the recycle bin. Only do this to move to another password manager, then delete the file.

    The columns are Bitwarden's, which most password managers can import. Tags and password history are not included; the trash is left out. For a copy that stays protected, use Save encrypted backup instead.
